The Problem

Earth's orbit is getting crowded

Decades of launches have left tens of thousands of tracked objects — dead satellites, spent rocket stages, and fragments from past collisions — circling the planet at thousands of kilometers per hour. Every one of them is a potential threat to the active satellites we rely on for communication, navigation, and weather forecasting.

What We Built

An end-to-end orbital awareness system

01

Real-Time Tracking

Search a live catalog of ~19,000 satellites and debris, track up to 8 at once, and watch their SGP4-propagated positions update live — or fast-forward up to 5 hours to see where they'll be.

02

Collision Risk Screening

Every tracked satellite is continuously screened against the full catalog for its closest predicted approach over the next 5 hours, scored into Critical/High/Moderate/Low risk bands.

03

3D Orbital Visualization

An interactive globe renders live orbital paths and markers in a way that's intuitive to explore, not just read as a table.

04

Close Approaches & Alerts

Browse every close approach for each tracked satellite, grouped by satellite, plus a live Alerts feed pulled straight from the backend's own catalog-wide scan — every Critical risk approach right now, not just the ones you're tracking here.

05

Distance-Over-Time Charts

Click the chart icon next to any tracked satellite to plot its distance to each nearby object across the next 5 hours — computed live in the browser, not a stored snapshot.

Help & About

How to use this

On this site

Search for any tracked object by name or NORAD ID, select up to 8 to track live, and fast-forward up to 5 hours to see where they'll be. Every tracked object is continuously screened for its closest predicted approach, shown in the Risk, Close Approaches, and Alerts panels.

Telegram bot

Message @space_debris_alert_bot to get pinged directly when a satellite you care about is heading into a critical risk close approach — no need to keep this page open.

  • /watch <NORAD id or name> start watching a satellite
  • /unwatch <NORAD id or name> stop watching
  • /list see what you're watching
  • /lookup <NORAD id or name> live scan any object right now
  • /alerts every critical-risk approach, catalog-wide

API

The same data powering this site is available as a public read API — no key required. Base URL: https://satellite-risk.vercel.app

  • GET /api/satellites/:noradId TLE + info for one object
  • GET /api/satellites/:noradId/conjunctions its latest close approaches
  • GET /api/alerts every critical-risk approach, catalog-wide, right now
